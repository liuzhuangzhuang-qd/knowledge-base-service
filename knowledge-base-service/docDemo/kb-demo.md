# 知识库测试示例文档

## 1. 公司简介

星云智库是一家面向企业知识管理场景的软件服务商。
公司提供文档接入、语义检索与智能问答能力，帮助团队高效获取可靠信息。
总部：上海。
成立时间：2021 年。
核心使命：让知识可检索、可追溯、可复用。

## 2. 产品模块

系统当前包含以下核心模块：

- 用户认证与权限控制
- 知识库创建与管理
- 文档上传与解析
- 文本切片与向量化
- 混合检索（关键词 + 向量）
- 基于检索结果的问答
- 会话历史与反馈管理

## 3. 支持的文档类型

目前支持上传的文件类型：

- `.txt`
- `.md`
- `.docx`

默认最大文件大小：20 MB。

## 4. 接口速览

- 创建知识库：`POST /api/kbs/create`
- 查询知识库列表：`GET /api/kbs/getList`
- 上传文档：`POST /api/kbs/upload?kb_id=<id>`
- 查询文档列表：`GET /api/kbs/documents/getList?kb_id=<id>`
- 发起问答：`POST /api/kbs/chat?kb_id=<id>`

## 5. 部署说明

推荐运行环境：

- Python 3.11
- FastAPI
- PostgreSQL
- Docker / Docker Compose

关键环境变量：

- `DATABASE_URL`
- `SECRET_KEY`
- `QWEN_API_KEY`
- `QWEN_BASE_URL`（可选，使用默认地址时可不填）

## 6. 常见问题排查

### 问题一：上传接口返回 400

可能原因：

- 文件扩展名不在支持范围内
- 文件大小超过上限

### 问题二：问答接口返回 503（Qwen 配置错误）

可能原因：

- `QWEN_API_KEY` 未配置或为空
- 大模型服务地址配置错误

### 问题三：文档列表接口返回 404

可能原因：

- `kb_id` 不存在
- 当前登录用户无该知识库访问权限
